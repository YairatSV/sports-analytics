Transparencia de datos

Los marcadores proceden de una fuente externa. Una consulta exitosa no significa que el proveedor publique cada evento al instante. Las predicciones se mostrarán separadas de los resultados oficiales.

  • No se requiere una clave API en esta primera fuente.
  • No se guardan credenciales en el navegador.
  • El backend FastAPI ya tiene una estructura inicial; PostgreSQL cuenta con un esquema preparado, pendiente de conexión y despliegue.
